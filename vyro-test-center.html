Como testar os módulos Node.js

Abra um terminal na pasta do projeto e execute:

powershell -ExecutionPolicy Bypass -File .\testar-vyro.ps1

O script executa testes automatizados e grava um relatório JSON local em test-results/. Os testes não comprovam integração com o aplicativo C++.

Aplicativo Windows

Ainda não há executável VYRO nativo validado. A solução fonte do Notepad++ está em PowerEditor/visual.net/notepadPlus.sln. Para testar um build Windows é necessário configurar e validar a toolchain C++.
