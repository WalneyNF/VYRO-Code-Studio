## Regras
1. O dragão oficial é o ícone do aplicativo e deve aparecer no README e na página Sobre.
2. Nome visível do produto: **VYRO Code Studio**. Não usar o nome da base original como marca principal.
3. Manter referências ao Notepad++ nos créditos, na licença, na documentação de origem e nos identificadores internos necessários para compatibilidade.
4. Preferir interface escura, legível, sem animações excessivas.
5. Verificar contraste, legibilidade, escalonamento de DPI e versões de ícone em 16/24/32/48/64/128/256 px.
6. Nunca afirmar integração com IA, Unreal, Unity ou Godot sem testes reais.
7. Cada lançamento deve testar inicialização, ícone no Explorer/barra de tarefas, menu Sobre, sintaxe, abertura/salvamento, plugins e modo escuro.
